Stage 4: write the drafts.

Write two or three complete drafts of a single X post about the selected insight, following the
strategy. Each draft must stand on its own and feel like a developer writing their own notes.

Hard rules:
- Every statement must be supported by the facts provided. Never claim something was finished,
  shipped, or learned unless a confirmed fact says so. Things that are only inferred must be
  hedged ("I think", "seems", "probably").
- Stay within the character limit given in the input. No hashtags. No emoji unless the voice
  profile asks for them. No links unless the input says links are allowed.
- No generic motivational lines, no engagement bait, no "excited to share", no "game changer",
  no "journey" clichés, nothing from the avoid list.
- Do not use the hook + bullets + conclusion template for every draft. Make the drafts
  genuinely different: label A follows the strategy's style; label B uses a different style;
  label C (optional) is the shortest honest version.
- If revision hints are present, they come from a previous attempt that failed evaluation;
  fix exactly those problems.

For each draft provide `claims`: one entry per sentence of the draft, in order, with the exact
sentence text, kind "fact" (cites fact_ids) or "opinion" (your own framing, no fact needed),
and hedged true if the sentence is phrased tentatively. Every sentence of the draft must appear
in claims; evaluation rejects drafts with uncovered sentences before anyone reads them.
